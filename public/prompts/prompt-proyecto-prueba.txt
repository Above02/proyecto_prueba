Actúa como un equipo multidisciplinario integrado por:

- Senior Frontend Developer.
- UI/UX Designer especializado en productos digitales y portafolios.
- Especialista en React, TypeScript y Vite.
- Especialista en diseño responsive, accesibilidad y rendimiento.
- Especialista en GitHub y despliegues con Vercel.

Diseña y desarrolla un sitio web de portafolio conceptual llamado **DATA INTELLIGENCE**, enfocado en ciencia de datos, analítica, inteligencia artificial, business intelligence, modelado estadístico y automatización.

El objetivo es comunicar una identidad profesional que convierta información compleja en conocimiento útil y decisiones inteligentes. El sitio debe transmitir criterio analítico, claridad, rigor, curiosidad y dominio tecnológico.

No entregues únicamente una maqueta, una explicación o fragmentos aislados. Construye una experiencia web completa, coherente, responsive, mantenible y lista para desplegar.

## 4. Dirección de arte e identidad visual

### Concepto

Un laboratorio editorial de datos: preciso, contemporáneo, minimalista y sofisticado. Evita el aspecto de plantilla corporativa genérica o dashboard administrativo.

### Paleta y superficies

- Fondo principal azul casi negro: `#080B12`.
- Superficie secundaria: `#0E131D`.
- Superficie alternativa: `#0C111A`.
- Texto principal: `#E9EDF5`.
- Texto secundario y muted: grises azulados cercanos a `#8A94A6`.
- Líneas divisorias: blanco azulado con opacidad baja.
- Acento azul claro: `#9DC5FF`.
- Elementos luminosos: azules fríos y brillos discretos.

Centraliza los colores en variables CSS para que puedan ajustarse sin buscar valores dispersos.

### Tipografía

- Utiliza Manrope o una sans-serif moderna para titulares y texto de interfaz.
- Utiliza DM Mono o una tipografía monoespaciada equivalente para numeración, etiquetas técnicas, coordenadas y microcopy.
- Mantén jerarquías claras, títulos grandes, interlineado cómodo y párrafos de lectura sencilla.
- Los acentos de color deben destacar palabras concretas sin competir con el contenido.

### Composición

- Mucho espacio negativo.
- Líneas horizontales finas.
- Numeración de secciones.
- Etiquetas técnicas pequeñas en mayúsculas.
- Tarjetas con bordes sutiles, sin sombras pesadas.
- Alineaciones limpias y consistentes.
- Animaciones elegantes, nunca distractoras.

### Visual principal del Hero

Construye una visualización abstracta de datos mediante CSS y elementos HTML:

- Halo luminoso difuminado.
- Dos órbitas elípticas con bordes azulados.
- Un núcleo circular con gradiente radial.
- Cuadrícula técnica dentro del núcleo.
- Etiqueta central `DATA IN MOTION`.
- Pequeños indicadores y microtextos como `FIG. 001 / SYSTEMS` y `SIGNAL DETECTED`.
- Un detalle de coordenadas o etiqueta de laboratorio como recurso estético, sin presentarlo como ubicación real.

No dependas de una imagen de stock para esta visualización. No utilices Three.js ni WebGL para este recurso; debe ser ligero y resolverse con CSS.

## 7. Animación e interacción

Utiliza GSAP y ScrollTrigger con moderación:

- Entrada escalonada de los elementos del Hero.
- Aparición suave del visual abstracto.
- Movimiento orbital lento de las órbitas del Hero.
- Revelado progresivo de secciones al entrar en el viewport.
- Transiciones discretas en tarjetas, chips y enlaces.

Requisitos:
- Respeta `prefers-reduced-motion: reduce`; desactiva las animaciones no esenciales si está activo.
- Limpia las instancias de GSAP y ScrollTrigger al desmontar componentes.
- Evita animaciones que provoquen saltos de layout o dificulten leer.
- No bloquees la navegación ni la interacción mientras se ejecutan animaciones.
- Mantén una experiencia fluida en dispositivos móviles.
